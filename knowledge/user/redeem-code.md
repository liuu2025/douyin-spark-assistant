# 兑换码

## 兑换码是做什么的

兑换码用于给某个抖音号增加或延长轮询资格。

轮询资格决定这个抖音号是否可以参与自动发送轮询。没有有效资格时，即使任务、轮次和登录状态都配置好了，也可能不会进入自动发送。

兑换码绑定的是抖音号，不是只绑定控制台账号。兑换到某个抖音号后，资格会加到这个抖音号上。

## 在哪里查看兑换码

点击左侧“我的兑换码”，可以查看你名下的兑换码。

列表会显示兑换码、类型、天数、状态、兑换到抖音号、兑换时间和发放时间。

未兑换的兑换码可以复制。已兑换的兑换码可能只显示隐藏后的码，用于查看记录。

## 怎么领取兑换码

有些兑换码来自“活动广场”。

1. 点击左侧“活动广场”。
2. 查看可领取活动。
3. 如果活动状态是“可领取”，点击“领取兑换码”。
4. 领取成功后，页面会显示兑换码。
5. 可以点击“复制兑换码”。
6. 兑换码也会加入“我的兑换码”。

每个账号每个活动通常只能领取一次。活动可能会显示未开始、已结束、已暂停、已领完或已领取。

## 怎么把兑换码兑换到抖音号

1. 点击左侧“抖音号”。
2. 找到要开通资格的抖音号，点击“进入”。
3. 在“自动发送设置”页签找到“抖音号资格兑换”。
4. 在输入框里粘贴兑换码。
5. 点击“兑换”。
6. 兑换成功后，页面会提示“兑换成功”。
7. 查看“轮询资格”是否显示已开通、剩余天数或有效期。

兑换后不可撤回。请确认当前详情页是你要兑换的抖音号。

## 兑换后什么时候生效

兑换成功后，系统会刷新当前抖音号信息。通常你可以马上在“轮询资格”里看到新的有效期。

如果这个抖音号原本还有有效资格，新兑换的天数会在原有效期后继续累加。如果原资格已经过期，通常会从当前时间开始计算新的有效期。

资格过期不会删除发送任务，也不会清空轮次绑定。只是过期后，这个抖音号不再参与自动发送轮询。

## 兑换码状态是什么意思

“未兑换”表示兑换码还可以使用。你可以复制后到抖音号详情页兑换。

“已兑换”表示兑换码已经被使用。列表里会显示兑换到哪个抖音号和兑换时间。

“已禁用”表示兑换码不能继续使用。请联系发放方或人工客服确认。

“已过期”表示兑换码或资格相关状态已经过期。请查看页面提示，必要时联系人工客服。

## 常见问题

### 为什么提示请输入兑换码

说明你点击“兑换”时输入框是空的。请先复制兑换码，粘贴到“抖音号资格兑换”的输入框里，再点击“兑换”。

### 为什么兑换码无效

可能是兑换码输入错误、复制时多了空格、兑换码不存在，或者兑换码已经不能使用。

请重新从“我的兑换码”复制完整兑换码。如果仍然失败，请联系人工客服，并提供兑换码状态和目标抖音号。

### 为什么提示兑换码已被使用

一张兑换码只能兑换一次。请进入“我的兑换码”查看它是否已经显示“已兑换”，以及兑换到哪个抖音号。

如果你认为兑换记录不正确，请联系人工客服。

### 为什么兑换成功后任务还是不发送

兑换码只解决轮询资格问题。任务能否运行还取决于抖音登录状态、自动发送开关、任务是否启用、是否选择轮次，以及轮次是否已经触发。

请进入抖音号详情页，依次检查“抖音登录状态”“自动发送”“轮询资格”和“发送任务”。
