# 新手开始使用

## douyin-spark 是做什么的

douyin-spark 是一个浏览器控制台。普通用户可以在这里管理自己的抖音号，查看抖音登录状态，配置发送任务，选择参与哪些发送轮次，并查看最近的运行记录。

你可以把它理解成一个网页工作台。你先登录 douyin-spark 账号，再把需要管理的抖音号登录进来。之后，每个抖音号都有自己的详情页，所有重要设置都在详情页里完成。

系统只能根据当前登录状态和任务配置尝试执行。它不会保证每次发送都一定成功。如果登录状态失效、任务没有启用、没有选择轮次、没有有效资格，或者抖音页面出现安全验证，任务都可能不会发送。

## 第一次进入后先做什么

第一次使用时，建议按这个顺序操作：

1. 进入登录页，使用账户 ID 或 QQ 邮箱登录。
2. 登录成功后进入仪表盘，先看是否已经有抖音号。
3. 如果还没有抖音号，点击仪表盘右上角的“添加抖音号”。
4. 在打开的远程浏览器里完成抖音登录。
5. 登录完成后，进入“抖音号”页面，点击对应抖音号右侧的“进入”。
6. 在抖音号详情页点击“验证登录状态”。
7. 登录状态有效后，进入“发送任务”页签，点击“新增发送任务”。
8. 设置发送话术、发送目标和参与轮次，然后保存。
9. 回到“自动发送设置”页签，确认“自动发送”是开启状态，并确认轮询资格有效。
10. 之后可以在“运行记录”页签查看最近结果。

这个顺序很重要。发送任务依赖抖音号登录状态、自动发送开关、轮次选择和资格状态。前面的条件没有准备好，后面的任务就可能不会运行。

## 常用页面在哪里

登录后，左侧侧栏会显示普通用户常用页面。

“仪表盘”用于查看总体状态和待处理事项。这里会提示登录状态异常的抖音号，也可以从这里添加抖音号。

“抖音号”用于查看你已经管理的抖音号列表。列表里有抖音号、抖音昵称、登录状态、自动发送状态、最近验证时间和最近错误。具体操作要点击“进入”到单个抖音号详情页。

“账号设置”用于查看账户 ID、QQ 邮箱、账号状态，也可以修改昵称和更改 QQ 邮箱。

“我的兑换码”用于查看你名下的兑换码、兑换状态、天数、兑换到哪个抖音号。

“活动广场”用于领取可用活动奖励。领取成功后会生成兑换码，兑换码会出现在“我的兑换码”里。

“教程中心”和右上角的帮助按钮用于查看页面帮助。

## 抖音号详情页最重要

大多数日常操作都在单个抖音号详情页完成。

进入方式是：打开左侧“抖音号”页面，在抖音号列表中找到目标抖音号，点击右侧“进入”。

详情页顶部会显示“抖音号 + 号码”。页面里有三个常用页签：

1. “自动发送设置”：查看抖音登录状态、最近登录状态验证、自动发送开关、自动加入新增轮次、轮询资格，也可以输入兑换码。
2. “发送任务”：新增、编辑、暂停或恢复发送任务。
3. “运行记录”：查看这个抖音号最近的任务运行结果。

如果你不知道问题出在哪里，优先进入这个详情页。这里能看到登录、资格、任务和运行记录四类关键信息。

## 什么时候需要等待

添加或重新登录抖音号时，需要等待远程浏览器启动。远程浏览器打开后，需要你在里面完成抖音登录。

点击“验证登录状态”后，也需要等待系统检查。验证可能很快完成，也可能因为网络、抖音页面加载或安全验证而变慢。如果页面提示验证耗时较长，可以稍后刷新，或重新进入抖音号详情页查看最近验证结果。

发送任务不会在保存后立刻保证执行。任务会在你选择的轮次触发时才有机会运行。固定时间轮次要等到对应时间；间隔轮次要等到下一次间隔触发。

## 常见问题

### 为什么我已经添加抖音号了，还是不能自动发送

可能是登录状态还没有验证，或者显示无效。也可能是自动发送开关处于暂停状态，发送任务没有启用，没有选择参与轮次，或者轮询资格未开通、已过期。

请进入抖音号详情页，先看“自动发送设置”。确认抖音登录状态有效、自动发送开启、轮询资格有效。再进入“发送任务”，确认任务已启用并且选择了参与轮次。

### 为什么任务保存了但没有运行记录

任务保存后，要等轮次触发才会产生运行记录。如果没有选择轮次，任务不会参与自动发送。如果选择的轮次还没到时间，也不会马上出现记录。

你可以进入“发送任务”编辑任务，查看“参与轮次”是否已经勾选。然后进入“运行记录”，点击“刷新”查看最新结果。

### 什么时候需要联系人工客服

如果你已经重新登录、验证登录状态、检查任务和轮次、确认兑换码资格仍然无法解决，可以联系人工客服。

联系时建议提供你的账户 ID、抖音号、看到的页面名称、最近错误文字，以及你刚刚做过的操作。这样人工客服能更快判断问题。
