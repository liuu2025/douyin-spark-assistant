# 账号登录和账号设置

## 账号登录是做什么的

账号登录用于进入 douyin-spark 控制台。这里的账号是你的控制台账号，不是抖音号。

控制台账号用来管理页面里的资料，例如你添加过哪些抖音号、有哪些兑换码、创建过哪些发送任务。抖音号需要在登录控制台后，再通过“添加抖音号”单独登录。

## 登录方式有哪些

登录页有两个登录方式。

“账户ID登录”适合已经知道自己账户 ID 的用户。账户 ID 会在“账号设置”页面显示。

“QQ邮箱登录”适合用 QQ 邮箱注册过的普通用户。输入注册时使用的 QQ 邮箱和密码即可。

两个登录方式是互斥的。切换登录方式时，页面会清空账号输入框，避免把 QQ 邮箱当成账户 ID，或者把账户 ID 当成 QQ 邮箱。

## 怎么登录

1. 打开登录页。
2. 在“登录”页签中选择“账户ID登录”或“QQ邮箱登录”。
3. 输入账户 ID 或 QQ 邮箱。
4. 输入密码。
5. 点击“登录”。
6. 登录成功后，页面会进入“仪表盘”。

如果页面提示登录失败，请先确认登录方式、账号和密码是否对应。用 QQ 邮箱注册的用户，推荐先选择“QQ邮箱登录”。

## 怎么注册

1. 在登录页点击“注册”。
2. 进入“用户注册”页签。
3. 输入 QQ 邮箱。
4. 点击“发送验证码”。
5. 到 QQ 邮箱查看验证码。
6. 输入 6 位验证码。
7. 设置注册密码。
8. 点击“注册并登录”。

注册成功后，系统会自动登录并进入控制台。

密码需要满足页面提示的规则：长度 6 到 20 位，至少包含 1 个数字和 1 个非数字字符。可以使用大小写字母、数字、英文点号、下划线和短横线。

## 忘记密码怎么办

1. 在登录页点击“忘记密码？”。
2. 输入注册或绑定过的 QQ 邮箱。
3. 点击“发送验证码”。
4. 到 QQ 邮箱查看验证码。
5. 输入验证码和新密码。
6. 点击“重置密码”。
7. 重置成功后，回到登录页，用新密码登录。

如果收不到验证码，请先确认 QQ 邮箱是否填写正确。也可以稍后重试。如果仍然收不到，请联系人工客服，并提供你的账户 ID 或 QQ 邮箱。

## 账户 ID 是什么

账户 ID 是 douyin-spark 给控制台账号显示的编号。它不是抖音号。

你可以在登录后的“账号设置”页面看到“账户ID”。联系人工客服时，提供账户 ID 可以帮助客服确认你的控制台账号。

## 怎么修改昵称

1. 登录后点击左侧“账号设置”。
2. 在“昵称”一行点击“修改”。
3. 输入新的昵称。
4. 点击“保存”。

昵称只影响控制台里的显示名称，方便你和客服识别账号。修改昵称不会改变账户 ID，也不会改变你管理的抖音号。

## 怎么更改 QQ 邮箱

1. 登录后点击左侧“账号设置”。
2. 在“QQ邮箱”一行点击“更改”。
3. 输入新的 QQ 邮箱。
4. 点击“发送验证码”。
5. 输入收到的 6 位验证码。
6. 点击“保存”。

新的 QQ 邮箱必须是标准的数字 QQ 邮箱，例如 123456789@qq.com。更改成功后，后续登录、找回密码和接收验证码都会使用新的 QQ 邮箱。

## 常见问题

### 为什么提示请输入登录信息

通常是账号或密码没有填写完整。请确认当前选择的是正确登录方式，并填写对应的账户 ID 或 QQ 邮箱，再输入密码。

### 为什么 QQ 邮箱格式提示不正确

账号设置里的更改 QQ 邮箱要求使用数字 QQ 邮箱。请检查是否包含空格、中文符号，或是否不是 qq.com 地址。

### 为什么账户状态显示已禁用

“已禁用”表示当前控制台账号可能不能正常继续使用。你可以先确认是否登录了正确账号。如果仍然显示已禁用，请联系人工客服处理。
