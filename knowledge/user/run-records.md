# 运行记录

## 运行记录是做什么的

运行记录用于查看发送任务最近有没有运行，以及运行结果是什么。

它可以帮助你判断任务是成功、失败、部分成功、跳过，还是仍在运行中。看到失败原因后，通常可以知道下一步应该检查登录状态、任务配置、目标匹配、轮次或资格。

运行记录不能保证说明所有历史情况，但它是排查“为什么没有发送”的重要入口。

## 在哪里查看运行记录

1. 点击左侧“抖音号”。
2. 找到目标抖音号，点击“进入”。
3. 打开“运行记录”页签。
4. 默认会显示“最新记录”。
5. 可以点击“刷新”查看最新结果。

运行记录表格里会显示状态、错误码、最近错误、周期开始、运行 ID、任务 ID、开始时间和结束时间。部分页面还会显示轮次 ID。

## 怎么筛选运行记录

运行记录顶部可以切换查看方式。

“最新记录”用于快速查看最近结果。

“全部记录”用于查看更完整的记录列表。

“按月份”可以选择一个月份。

“按日期”可以选择某一天。

你还可以按任务 ID、轮次 ID、错误码和状态筛选。筛选后如果想恢复默认，可以点击“重置”。

## 运行状态是什么意思

“运行中”表示系统已经开始处理，还没有结束。

“发送中”表示任务正在尝试发送。

“已发送”表示这次任务运行完成，并且结果是成功发送。

“部分成功”表示任务里可能有一部分目标成功，一部分目标没有成功。请查看最近错误，判断是否需要调整目标或重新检查。

“已跳过”表示这次没有执行实际发送。可能是重复轮次、条件不满足、目标不适合发送，或系统判断本次不应继续。

“失败”表示这次运行没有成功。请查看“错误码”和“最近错误”。

## 常见错误怎么处理

如果看到“登录状态不可用”“登录态已失效”“登录文件缺失”或“登录账号不匹配”，请先进入“自动发送设置”，点击“验证登录状态”。如果仍然无效，点击右上角“重新登录”。

如果看到“发送目标未找到”“群聊未找到”或“目标匹配不唯一”，请进入“发送任务”编辑任务，检查好友备注、群聊名称关键词和匹配方式。

如果看到“发送配置无效”，请检查发送话术、发送目标和参与轮次是否填写完整。

如果看到“需要安全验证”，请重新登录抖音号，并在远程浏览器里处理抖音页面提示。

如果看到“打开抖音页面失败”“输入框未找到”“私信入口未找到”等页面相关错误，可以稍后重试。抖音页面可能变化或加载异常。多次出现时请联系人工客服。

## 为什么没有运行记录

没有运行记录不一定是故障。可能是任务还没有到轮次触发时间。

也可能是任务没有选择轮次、任务处于暂停状态、抖音号自动发送暂停、轮询资格未开通或已过期，或者登录状态无效导致任务无法启用。

请先进入“发送任务”确认任务启用并选择轮次，再进入“自动发送设置”确认登录状态、自动发送和轮询资格。

## 常见问题

### 为什么状态是已跳过

“已跳过”表示系统没有继续实际发送。可能原因很多，例如同一轮次已经处理过、条件不满足，或目标不适合继续。

请先看“最近错误”。如果没有明确错误，可以检查任务是否重复配置、轮次是否刚刚触发过，以及任务目标是否填写准确。

### 为什么显示部分成功

“部分成功”表示这次运行不是完全失败，但也不是所有目标都成功。

请查看最近错误。常见处理方式是检查目标匹配词是否过宽或过窄，确认目标是否存在，必要时调整发送任务后等待下一次轮次。

### 失败后要不要马上重复操作

不要盲目反复点击或频繁重试。先根据错误原因处理。

登录类错误先重新登录或验证。目标类错误先修改目标匹配。资格或轮次问题先检查自动发送设置和参与轮次。如果仍然失败，请联系人工客服。
